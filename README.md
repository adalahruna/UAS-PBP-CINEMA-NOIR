CINEMA NOIR adalah proyek UAS untuk mata kuliah Pemrograman Berbasis Platform (PBP). Aplikasi ini dibuat untuk mendemonstrasikan fitur dasar sistem informasi bioskop (contoh: daftar film, detail film, pemesanan tiket).
 Fungsi utama: menampilkan daftar film, melihat detail, memesan tiket (simulasi), manajemen jadwal, dsb.
